## Problems and fixes
1. **(Blocker, AT 6)** Fix in Again.kt: add `const val DROPPED = "Dropped, sir."`, change the `said` guard to `if (l.isEmpty() || l == NOTHING || l == DROPPED) return`, and in Reflex.kt return `Hit(Again.DROPPED, true)` in the drop-it branch. Then remove `@Ignore` from `AgainIndepTest.at6ThroughTheService`. Verified: with this change all 15 Again tests pass.
2. **(Works) Live-talking answers are never recorded.** When a Gemini key is set, live talking is on by default (`Live.ready`), and those answers are spoken by `Live`, not by `handle`/`sayFirst`. So after a live conversation, "Jarvis, say that again" replays an older line from up to 10 minutes before, or says "Nothing to repeat". Fix in Live.kt: next to both `Prefs(context).addTurn("assistant", m)` (lines ~201 and ~334) add `Again.said(m, System.currentTimeMillis())`.
3. (Minor) A later identical real line is never recorded: `lastReplay` stays set after the replay, so if Jarvis really says the same line again ("Done, sir.") its time isn't refreshed. Fix in `said`: replace the `l == lastReplay` check with `if (l == lastReplay) { lastReplay = ""; return }` (included in the verified fix above).
4. (Minor, Feel) Bare "sorry" and bare "again" are in `WHOLE`. Saying "sorry" to a customer during the follow-up window makes Jarvis replay his last line. The spec lists only "Sorry, what?". Fix: remove `|sorry|` and `|again` from `WHOLE`.
5. (Minor, L8 found here) A held catch-up that is queued in `pending` because he was busy is later replayed by `finishTurn` as `sayFirst(line, listenAfter)`, which brings the alert chime back. Fix: make `pending` a `Triple<String, Boolean, Boolean>` that carries `chime`, and call `sayFirst(line, listenAfter, chime = chime)`.
