## Problems
1. **High — times with a no-break space are not read, so per-hour silently turns off.** Android 13+ formats times with U+202F (narrow no-break space) before AM/PM, and many apps use U+00A0. `\s` in Java regex does not match either.
   Repro: `OfferMath.minutes("Deliver by 7:40 PM", 19*60)` → `null` (expected 40). `parse("$6.00 | 1.5 mi | …")` → `null` (no call-out at all). Test `l2_realWorld_nonBreakingSpaces` fails. Result on the road: the $6 / 40 min order gets "Good one, sir, take it." instead of "I'd pass."
   Fix (verified: all tests pass with it) — first line of both `parse` and `minutes` in `OfferMath.kt`:
   ```kotlin
   fun parse(all0: String, nowMinutes: Int): Offer? {
       val all = all0.replace(' ', ' ').replace(' ', ' ')
   fun minutes(all0: String, nowMinutes: Int): Int? {
       val all = all0.replace(' ', ' ').replace(' ', ' ')
   ```
2. **Medium — any out-of-range "N min" on the screen blocks the "Deliver by" fallback.** `minutes()` returns null on the first "N min" match even if it's out of range, so "Pickup in 2 min | Deliver by 7:40 PM" → unknown (should be 40). The regex also matches any "N min" anywhere on the Dasher screen, not just the card.
   Fix: take the first in-range duration, else fall through:
   ```kotlin
   Regex("(\\d{1,3})\\s?(?:min|mins|minutes)\\b", RegexOption.IGNORE_CASE).findAll(all)
       .map { it.groupValues[1].toInt() }.firstOrNull { it in 3..120 }?.let { return it }
   ```
3. **Medium — the call-out now waits for the diary write.** In `OfferJudge.check`, `remember()` (parse + re-serialise up to 1500 JSON entries, ~100 KB, on the accessibility/main thread) runs *before* the ACTION_SAY intent. Fix: send the ACTION_SAY first, then save on a background thread: `thread { try { remember(p, hour, o) } catch (e: Exception) { Problems.log(context, "offer diary: ${e.message}") } }` (import `kotlin.concurrent.thread`).
4. **Low — decimals are read digit by digit.** "4.05 dollars a mile" → Piper/eSpeak says "four point zero five dollars". Same as before L2, but L2 adds words to the line. Fix in `OfferMath.line`: speak as "4 dollars 5" / "89 cents": `val c = Math.round(rate*100); if (c < 100) "$c cents" else "${c/100} dollars ${if (c%100==0L) "" else (c%100).toString()}".trim()` and same for pay ("8 dollars 50").
5. **Low — no sanity limit on the hourly minimum.** A misheard "judge offers at 2 an hour" makes every timed offer "great" on the hourly side. Fix in `setRule`: `perHour?.takeIf { it in 5.0..100.0 }?.let { … } ?: if (perHour != null) return "Keep it between 5 and 100 an hour, sir."`.

- **At home, Google Home / Govee:** not involved; Dasher closed → no accessibility events from DoorDash → nothing happens. OK.
- **Noisy car / mishear:** "judge offers at 22 an hour" misheard as "2 an hour" → accepted without check (problem 5). The call-out itself does not depend on hearing.
- **No signal:** all local (accessibility text + on-phone maths + on-phone voice); works offline. Changing the hourly minimum needs Claude, so not offline.
- **Vague ask:** "is that a good one?" → goes to Claude; not part of L2.
- **Follow-up within 3 s:** call-out is not a conversation turn; no change.
- **Misfire check:** code only builds a sentence and sends ACTION_SAY. No tap, accept, decline, message, purchase or post anywhere in the L2 path. Safe.
