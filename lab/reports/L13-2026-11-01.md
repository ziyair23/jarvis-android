## Keys, cost, network (as asked)

- **Quota/cost:** 3 read calls per ask (channels, playlistItems, videos = 1 unit each) out of 10,000 a day free. No paid API. The reflex costs no Claude tokens. Cost 5.

- **Key fallback:** YouTube key → Google voice key → Gemini key, first non-blank, as the spec says. Only that one key is tried (problem 3).
- **Read-only:** GET requests only. Never posts, comments or uploads. Safe 5.

## Problems
1. **(Blocker, Works) Channel links with a tab look up a stranger's channel.** Pasting `https://www.youtube.com/@marcus27/videos` (copied from the Videos tab) → `channelQuery` takes the last path part → `forHandle=@videos` → Jarvis reads out **someone else's channel** as his. Same for `/featured`, `/shorts`, and `…/channel/UC…/videos`. A `youtu.be/<video>` link becomes `@<videoId>`. The builder's `channelInput` test strips "/videos" before calling, so it never sees this.
   **Fix (verified: all 15 YouTube tests pass with `channelLinkWithATab` un-ignored)**, replacing `channelQuery`:
   ```kotlin
   fun channelQuery(input: String): String? {
       val s = input.trim().substringBefore('?').trimEnd('/')
       if (s.isEmpty()) return null
       val segs = s.split('/').filter { it.isNotEmpty() }
       segs.firstNotNullOfOrNull { Regex("^UC[A-Za-z0-9_-]{22}$").find(it)?.value }?.let { return "id=$it" }
       val h = (segs.firstOrNull { it.startsWith("@") } ?: segs.singleOrNull() ?: return null).removePrefix("@")
       if (!Regex("^[A-Za-z0-9._-]{3,30}$").matches(h)) return null
       return "forHandle=@$h"
   }
   ```
   Then remove `@Ignore` from `YouTubePulseIndepTest.channelLinkWithATab`.
2. **(Hardening) Key in the URL.** The key is sent as `&key=` in the query string. **Fix:** in `YouTube.get`, drop `"&key=…"` and add `c.setRequestProperty("X-Goog-Api-Key", key)` (Google APIs accept it). As a safety net, log `e.message?.replace(Regex("key=[^&\\s]+"), "key=…")`.
3. **(Minor) Quota used up or a restricted key.** A 403 `quotaExceeded` says "Turn on the YouTube Data API…", which is wrong. With a voice key restricted to Text-to-Speech, the Gemini key is never tried. **Fix:** in `get`, on 403 read `c.errorStream` and, if it contains `quotaExceeded`, throw `Bad("YouTube's daily limit is used up, sir. Try again tomorrow.")`. In `pulse`, on `NOT_ALLOWED` retry once with the next non-blank key in `listOf(p.youtubeKey, p.ttsKey, p.geminiKey)`.
4. **(Minor, Fast) No fast path offline.** **Fix:** at the top of `pulse`, `if (!Brain(context).isOnline()) return YouTubePulse.NO_SIGNAL`, and cut connect/read timeouts to 5 s.
5. **(Minor) Loose phrasings.** "how are my subs" and "how's the channel" are taken (could be sandwiches or TV). Harmless (read-only), but **fix:** drop `subs` from the first alternative's noun list unless "my" is present.
