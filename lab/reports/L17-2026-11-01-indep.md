## Problems
1. **(Blocker, Works) Ordinary words sound-match short names and swallow his request.** Repro: Mom called this morning. 7 PM: "Jarvis, make a note for me to pick up diapers." → `parse` → `AddFor("me to pick up diapers")` → `resolve` sound branch: `sound("me") == sound("mom") == "m"` → *"Noted for Mom, sir."*, saved as a call note "to pick up diapers". The reminder never goes to Claude and only comes back the next time Mom rings. Same for Mia/May/Mo ("note for me…") and Tia/Ty ("make a note about the oil change" → "Noted for Tia"). The spec only allows a match "if it sounds the same".
   **Fix (verified: all 18 L17 tests pass, including the un-ignored one), in CallNotes.kt:**
   ```kotlin
   private val NOT_NAMES = setOf("me", "my", "myself", "the", "a", "an", "it", "this", "that", "him", "her", "them", "us", "you", "today", "tomorrow", "tonight", "later")
   private fun soundOK(spoken: String, name: String) = spoken.split(" ").first() !in NOT_NAMES && sound(name).replace(" ", "").length >= 2
   ```
   and guard every sound comparison with it: in `findWho` → `names.firstOrNull { soundOK(k, key(it)) && sound(key(it)) == sound(k) } ?: names.firstOrNull { soundOK(k, key(it).split(" ").first()) && sound(key(it).split(" ").first()) == sound(k) }`; in `resolve` → `words.size >= n && soundOK(words.take(n).joinToString(" "), c.first) && sound(words.take(n).joinToString(" ")) == sound(c.first)`. Then remove `@Ignore` from `CallNotesIndepTest.ordinaryWordsAreNotNames`.
2. **(Safe / AT 9) Notes leave the phone when the Google voice is on.** Every spoken line goes through `JarvisService.speak`, which sends the text to Google Cloud TTS (`CloudVoice.synth`) whenever `prefs.ttsKey` is set. So "Abbey is calling, sir. Your note: she owes you twenty." and the "what are my notes" read-back are uploaded to Google.
   **Fix:** in CallNotes add `private val priv = java.util.Collections.synchronizedSet(LinkedHashSet<String>()); fun markPrivate(s: String): String { priv.add(s); if (priv.size > 20) priv.remove(priv.first()); return s }; fun isPrivate(s: String) = priv.contains(s)`. Wrap the note-bearing results: `ringLine(...)` return (when `note` isn't empty) and the `Cmd.Read` reply with `markPrivate(...)`. In `JarvisService.speak` change `val key = prefs.ttsKey` to `val key = if (CallNotes.isPrivate(text)) "" else prefs.ttsKey`, and in `speakHouse` add `|| CallNotes.isPrivate(text)` to the condition that falls back to `speak`. That way Piper or the phone voice says it on the phone.
3. Minor (Feel): read-back drops capitals and punctuation (Reflex `norm` lower-cases, strips "$", and strips a trailing "now/please/sir"), so "she owes me $20 now" is stored as "she owes me 20". **Fix:** in `Reflex.handle`, pass `CallNotesStore` the original text with only the wake word and leading "please/can you" removed, and only use `norm(text)` for `parse` matching; take the note body from the original by the same word offset.
